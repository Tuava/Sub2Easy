# v0.4.0 · 五路自查、交互改进与列表用量

## 历史设计记录

本文保留 v0.4 的交互设计与数据来源说明。当前默认配置和安装步骤以 README 为准，当前测试数量应重新运行测试获得，不把历史本机部署过程当作发布验证。

## 用量直接在列表里

本地账号与全站账号都有“用量 / 重置”列：

- OpenAI OAuth 的5小时、7天已用比例，重置时间及快照新鲜度；
- 今日本站请求数、Token数及账号口径费用，直接显示；
- 展开行内小项可查看标准费用、用户口径费用及统计口径，不必打开另一个页面；
- 没有绑定的本地账号显示“未绑定云端”；其他站点绑定不串用量；
- 缺失显示未知，明确的0才显示0；窗口已经到重置时间时显示“旧窗口已结束”，不自行假定恢复到0%；
- “刷新用量”只请求当前页或所选已绑定账号，每批最多50个；按60秒缓存去重，一个采集任务最多4并发，不依赖模型探活。

用量在独立只读线程采集，不占用授权/部署线程。页面采集状态不阻塞勾选和编辑。切站点/更换管理员Key/锁库会清空缓存，旧任务晚到也不能写回新站点缓存。

## 数据来源与边界

源码核实基线 `Wei-Shaw/sub2api@98d86915becae9fe9491a91ffc6defd5235c8d2b`。

每个账号最多两个逻辑GET：

1. `GET /api/v1/admin/accounts/:id`：只读现有 `extra.codex_5h_*`、`codex_7d_*`、`codex_usage_updated_at`。
2. `GET /api/v1/admin/accounts/:id/today-stats`：查询本站日志。

**没有调用 `/accounts/usage/batch`。** 上游对OpenAI即使 `force=false` 也可能主动请求模型、写回字段及清错，不能当成被动读取。也未采用可能在部分失败时补0的 today-stats/batch。

今日由sub2api服务端时区定义，接口没有返回具体时区。tokens含输入/输出/缓存创建/缓存读取；费用是本站日志统计，不是上游订阅余额。当前只有OpenAI OAuth的额度窗口适配，其它平台可显示今日日志，窗口显示未知/不支持。

底层Client对GET最多3次尝试，因此每账号最多6次网络尝试，不是严格两次。采集客户端超时5秒，整批约120秒截止后不再开始新请求；已发请求会按自身截止完成。只缓存规范化数据，最多2000个账号，缓存不包含Token、Cookie、邮箱或代理认证。

## 优先交互改进

- 主操作只有“导入服务器并上线”，仅授权、只写入、导出等在“更多”中，名称写清不会自动上线。
- 本地入库不要求先配置站点；服务器部署前才要求站点、模板和隔离确认。
- 切换TXT/JSON格式不直接清空已输入内容；部分失败保留输入，便于修正。
- 定时刷新不抢正在操作的行、展开菜单或确认窗口的焦点，重复请求去重。
- 选择计数显示是否包含其他页；变更筛选清理隐藏选择，避免错误批量操作。
- 导入确认冻结当前模板及站点修订；刷新后模板变化不会悄悄改变这次提交。
- 整批全部被拒绝时，弹窗保留具体错误，不显示“提交成功”；任务摘要跟随真实任务终态，不永久显示排队。
- 保存左侧连接配置不重置右侧未保存模板；未知/过期用量与已上线状态使用不同文案。
- 每个任务支持“停止任务”：queued立即取消，running记录停止请求并在后续副作用检查点生效；已发出的请求不能撤回，不假装取消即回滚。

## 验证范围

验证包括 Python 回归测试、动态 DOM 测试、临时凭据库中的本地 HTTP 验证。jsdom 交互测试不等同于真实浏览器逐像素验收；用量数值仍由当前站点的实际响应决定。

Python测试包括旧功能回归、五路专项、集成API和本地真实HTTP模拟。动态UI测试使用jsdom加载实际HTML和脚本，不用浏览器秘密或生产账号，覆盖：两表七列、用量展示/0/未知/过期、确认模板冻结、批量失败提示、焦点保持、格式切换、本地离线入库、锁库不被迟到结果重新填充、任务摘要正确性。

安装前端测试依赖仅用于开发，不增加运行时CDN或前端构建要求：

```bash
uv run python -m unittest discover -s tests -v
npm ci --ignore-scripts
npm run test:ui
uv build
```

## 尚未完成 / 不能夸大的部分

- 自动备用池补位、通知渠道、操作系统开机自启、主密码轮换和完整备份恢复界面仍未实现。
- 上游无CAS条件更新，无法从客户端消除最后读回与写入间的所有竞态；未知写入仍需对账，不为避免点击而重复建号。
- NVT返回个人免费workspace而非团队workspace的问题不由本次交互修改解决；具体账号是否恢复必须独立用实际状态验收。
- 快照不是实时上游余额，不用测试通过或本地模拟数字证明真实账号健康。
- 本地服务重启后仍需主密码解锁；本轮不在配置中保存主密码绕过这个限制。
