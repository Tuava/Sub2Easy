# 自动匹配、批量绑定与全站筛选

## 操作入口

- **号池总览 → 单号“绑定”**：不再要求先输入云端 ID；读取当前站点完整账号快照，唯一可校验匹配可直接绑定，有歧义时打开候选详情。
- **多选本地账号 → 批量自动绑定**：按已选本地 ID 工作，不把当前可见列表之外的账号偷偷加入。跨页选择有明确计数；筛选器变更会清理选择（搜索/状态筛选保留选择但计数说明含其他页）。
- **绑定处理中心 → 匹配全部未绑定账号**：面向全部未绑定本地账号，前端按每批最多 100 个提交；每一批完整读取云端后开始匹配。
- **重试待处理项 / 单行重新匹配**：成功项不重复绑定，其他未处理记录不会因为重试一行而消失。

绑定本身只建立本地身份到 cloud ID 的映射，不调用 NVT、不修改云端凭据或配置、不自动开启监控。

## 匹配依据与自动处理

1. 已有授权结果时，核对邮箱 + workspace + 已知 user_id。已知 workspace 可以消除同一邮箱多个组织空间的歧义。
2. 未有授权结果时，使用本地规范化邮箱与云端 credentials.email 精确匹配，并要求云端存在 chatgpt_account_id。
3. 名称匹配范围：本地邮箱、Sub2Easy 的确定性 `s2e-<local-id>` 创建名称、已有授权导出中的账号名。
4. 时间：优先采用授权导出的 exported_at，其次是本地材料 imported_at，与云端 created_at 比较。时间差不超过 1 小时可作为弱候选线索，其他已有身份/名称候选也显示完整时间差。
5. 旧版数据没有 imported_at 时显示未知，不用随时变化的 updated_at 伪造导入时间，也不根据“最近更新”替代云端创建时间。

权重仅用于候选排序（workspace、邮箱、名称、时间），不代替唯一性判断。同邮箱两个候选即使一个更近，也保留歧义；被其他本地身份占用的重复号仍参与歧义判断，不能悄悄排除后自动选择另一号。

名称/时间相近但邮箱不同、缺少身份元数据、平台不符、影子账号，不会自动绑定。候选列表仍显示其匹配原因和冲突说明，按钮不可用。手动选择用于消除**身份一致的多个候选**的歧义，不绕过已有身份冲突。

## 候选详情

显示 cloud ID、账号名、邮箱、workspace、平台/类型、状态/调度、分组名称与 ID、代理名称与 ID、并发、优先级、指纹模式、创建/更新/最近使用时间，以及与本地参考时间的差值。

候选支持名称/邮箱/ID/workspace 搜索、“仅可绑定”开关、匹配程度/时间接近/创建时间排序。选中后再次确认对应关系；提交时按当前站点连接修订和候选摘要重新读云端验证。创建时间、名称、身份、分组或代理变化会变为统一待处理错误，不继续绑定。

这不是远端事务快照：全量分页本身不是原子读，最终校验与本地保存之间仍有外部改动窗口；持续的账号身份校验由监控/写入入口继续执行。

## 统一结果列表

结果包含：绑定成功、已有绑定、唯一匹配、多个候选、未找到、有冲突、请求失败。每个本地账号独立处理；单号失败不回滚之前成功项。

完整快照读取失败时，本批全部标为读取失败，不使用残缺列表建立绑定。绑定记录和报告均在本地主密码库加密持久化。过程每完成一项更新报告；进程中断后不会自动重放，可以通过重新匹配核对已有绑定。

切换站点或管理员 Key 会清除候选报告和目录缓存，旧页面选定的候选不能提交到新站点。已有绑定关系本身不删除；“其他站点”可在本地列表筛选查看。

## 全站账号页

“刷新全站账号”完整读取当前已配置站点所有平台的账号，而不是只读本地导入号或者第 1 页。刷新成功后缓存**字段白名单**快照；页面筛选/翻页只读本地缓存，不持续打后台。

支持组合筛选：

- 名称、邮箱、云端 ID、workspace 搜索；
- 平台；active / inactive / error / 账号401 / 停止调度；
- 分组（包含未分组）；代理（包含直连）；
- 本地已绑定 / 未绑定 / 已监控；
- 创建起止日期（界面按本地时区日期，结束日包含全天）；
- 创建时间正倒序、名称、ID 排序；每页25条。

页面显示快照时间，缓存状态不等同实时运行状态；需要最新结果请刷新。

本地号池增加绑定站点、监控状态/待办、云端分组、云端代理、模板筛选，及更新时间/导入时间/名称排序、分页。云端分组/代理筛选依赖最近目录快照；不是直接拿“导入模板的目标分组”冒充真实云端分组。

## 数据边界

为了人工消歧和全站检索，绑定处理中心及云端目录显示完整邮箱/名称和平台身份元数据；只在本地已解锁会话返回。密码、TOTP、access/refresh token、代理认证、原始错误正文不会进入候选/目录 API。页面用 textContent 构建文本，不把云端账号名称作为 HTML 执行。

本地账号列表仍优先显示脱敏登录名，绑定后的搜索可以通过目录元数据匹配完整云端邮箱。未绑定本地账号的完整邮箱可以在绑定报告中核对，不把密码材料返回前端。

## 当前不做

不会通过相似名称强制覆盖身份，不会自动合并/删除重复云端账号，不会自动修正缺失的云端身份字段，不会把“名字最像”当作密码材料的归属证据。缺少资料需要先核对/补齐，再重新扫描。
